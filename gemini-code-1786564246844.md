# SKIN AURA — Minecraft Bedrock Creator Studio

**SKIN AURA** is a browser-based creator platform built exclusively for **Minecraft Bedrock Edition** players and developers. It allows creators to generate HD profile pictures, design custom pixel-art capes, and bundle skin packs into downloadable `.mcpack` files.

---

## 🚀 Quickstart & How to Run

Because **SKIN AURA** is built strictly using **vanilla HTML5, CSS3, JavaScript (ES6+), Canvas API, and JSZip**, no node server or build pipeline is required.

1. Clone or download this repository.
2. Open `index.html` directly in modern Web Browsers (Chrome, Firefox, Edge, Safari).
3. Alternatively, serve via any lightweight Web Server (e.g., Live Server in VSCode or `python3 -m http.server 8000`).

---
